# Emi Kobayashi

Personal website and portfolio, live at **[emikoba.com](https://emikoba.com)**.

![The Emi Kobayashi landing page](docs/landing-page.png)

## About

A multilingual marketing portfolio with light and dark themes, project case studies, and downloadable resumes in English, Japanese, and Chinese. Hosted on GitHub Pages with a custom domain.

## Stack

- Next.js and TypeScript
- Tailwind CSS
- Static export to GitHub Pages

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Site copy and profile data live in `src/data/profile.ts`.

## Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Local development server |
| `npm run build` | Production build |
| `npm run lint` | ESLint |
| `npm run generate-pdfs` | Rebuild resume PDFs |
